IWTLYTYDD Login UI
==================

A login page UI built as an HTML and CSS practice project.

About
-----
I created this project while learning and practicing HTML and CSS.
The design is based around the anime "I Want to Love You
Till Your Dying Day (Kimi ga Shinu Made Koi wo Shitai)".

Features
--------
• Responsive layout
• Glassmorphism / liquid-glass inspired design
• Full-screen background image
• Form validation using HTML
• CSS gradients and shadows
• Inset shadows
• Custom typography
• Responsive Flexbox layout

Made using:
------------
- Google Chrome (Version 153.0.8010.53 [Official Build] [64-bit])
- HTML5
- CSS3
- Visual Studio Code v1.138

Purpose
-------
The project is primarily for practice & there is no
intention to attempt actually making it functional.
I'm not quite satisfied myself yet but I'm still learning
